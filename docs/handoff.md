## Quick Context

RecruiteAI is an AI-powered recruiter platform for automated telephonic interviews. Users create jobs, upload resumes (PDF/DOCX), and the system uses AI agents to parse resumes, generate questions, conduct phone interviews via Twilio + OpenAI Realtime, and evaluate candidates.

## Decisions Made

1. **Auth**: JWT with email/password. Seed user: `dinesh.tomar@yopmail.com` / `Password@123`
2. **Resume formats**: PDF (pypdf) + DOCX (python-docx)
3. **Questions**: Auto-generated by LangChain agent from JD + resume (no manual editing)
4. **Storage**: Abstraction layer (local + S3). Start with local.
5. **Evaluation**: AI auto-scores (overall, technical, communication, experience) + remarks
6. **Concurrency**: One call at a time
7. **Frontend**: React + Vite + TypeScript + shadcn/ui + Tailwind v4
8. **Backend**: FastAPI + SQLAlchemy async + Alembic + LangChain
9. **4 Specialized Agents**: Resume Parser, Question Generator, Interview, Evaluation
10. **TDD**: Tests written before implementation, >80% backend coverage
